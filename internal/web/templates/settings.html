Drivers

The car doesn't say which driver profile is in use, so each driver's phone tells the hub instead. Trips are tagged with whoever checked in during the 30 minutes before the drive. You can also change the driver on any trip.

Set it up on a driver's iPhone (once per person)
  1. Shortcuts app → Automation → + → Bluetooth → choose the car → Is Connected → Run Immediately.
  2. Add Get Contents of URL: {{.DriverURL}}, method POST.
  3. Header Authorization = Bearer + the token (under Assistant above).
  4. Request Body JSON: key name, value the driver's name, e.g. Kevin.
